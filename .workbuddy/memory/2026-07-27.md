### 动效系统升级（全站覆盖 + 页面切换）
- **核心改动**：旧方案 `main > *` 只在首次挂载触发，App Router 导航时 main 不重挂载 → 切页面无动效。改用 `src/app/template.tsx`（Next.js 特殊文件，每次导航重新挂载），包裹 `<div className="page-stagger">`，其直接子元素（页面区块）每次切页都交错入场
- **CSS 动效系统**（`globals.css` 替换整个动效 section）：
  - `pageStaggerIn` + `.page-stagger > *` — 页面区块交错入场（translateY 14px→0，nth-child 递增 delay）
  - `staggerIn` + `.stagger > *` — 列表项逐个浮现（translateX -6px→0，nth-child 递增 delay）
  - `slideDown` + `.header-enter` — 导航栏首次从顶部滑入
  - `footerIn` + `.footer-enter` — 页脚首次从底部淡入上移
  - 保留：`nav-underline`、`post-link`、`theme-icon` 微交互 + `prefers-reduced-motion` 降级
- **组件改动**：header 加 `header-enter`、footer 加 `footer-enter`、PostList 的 `<ul>` 加 `stagger`、首页项目列表加 `stagger`、blog 年份容器加 `stagger`、文章详情 `<article>` 加 `stagger`、作品页 `<ul>` 加 `stagger`、关于页 `<article>` 加 `stagger`、标签页 `<ul>` 加 `stagger`
- 验证：全路由 200/404 正常，HTML 含 `page-stagger`/`header-enter`/`footer-enter`/`stagger` class
- **修复：CSS @keyframes 在 React reconciliation 时不可靠重触发**（即使有 key）。改用**状态驱动 CSS transition**：`template.tsx` 用 `useState(false)` + `useEffect` + 双重 `requestAnimationFrame` 切换 `page-out`→`page-in` class，浏览器看到真实属性变化 → transition 必然触发。CSS 改为 `.page-out > *`(opacity:0, duration:0s) → `.page-in > *`(opacity:1, 0.5s transition + stagger delay)。`.stagger` 也改为由父级 `.page-in`/`.page-out` 控制。layout.tsx 加 `<noscript>` 兜底。
- **修复**：template.tsx 改为 `"use client"` 客户端组件 + `usePathname()` 作 `key`，强制 React 销毁旧 DOM 重建新 DOM（纯 template.tsx 重挂载不可靠，React 可能复用 DOM 节点导致 CSS 动画不重新触发）
- **第三次修复（内联样式方案）**：CSS class 方案仍无效，改用纯 React 内联样式驱动——`template.tsx` 直接在 `style` 属性中控制 `opacity`/`transform`/`transition`，完全绕开 CSS 层。SSR 渲染 `opacity:0`，`useEffect` + `setTimeout(80ms)` 切到 `opacity:1`，transition 由浏览器原生处理。CSS 中删除了 `.page-out`/`.page-in`/`.stagger` 规则，只保留 header/footer 首屏动画和 hover 微交互。
- **用户要求删除所有动效**：三次尝试均无效，用户放弃动效。删除 `template.tsx`、CSS 中全部动画规则（`@keyframes slideDown`/`footerIn`/`.header-enter`/`.footer-enter`/`.nav-underline`/`.post-link`/`.theme-icon`/`.theme-icon-spin`）、所有组件中的动画 class（`stagger`/`header-enter`/`footer-enter`/`nav-underline`/`post-link`/`theme-icon`）、layout.tsx 中的 `<noscript>` 兜底、theme-toggle 中的旋转动画状态。保留主题切换功能本身（无动画）。
